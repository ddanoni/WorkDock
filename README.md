# WorkDock

WorkDock은 Windows에서 화면 캡처, 메모, 복사 기록, 기호와 단위 환산을 커서 옆의 작은 창으로 바로 쓰는 플로팅 업무 도구입니다. 프로그램을 켜면 큰 관리 창이 뜨지 않고 작업 표시줄에 남습니다. 필요할 때만 메뉴를 열어 도구를 꺼냅니다.

배포자: Yoon Sangwon  
현재 공개 버전: 0.10.10

대상: 64비트 Windows

이 저장소는 설치 파일과 설명만 두는 공개 배포 장소입니다. 소스 코드, 개발 기록, 테스트 자료, 사용자 데이터는 올리지 않습니다.

## 다운로드

최신 설치 파일은 [Releases](https://github.com/ddanoni/WorkDock/releases/latest)에 있습니다.

| 항목 | 값 |
| --- | --- |
| 파일 | `WorkDock_Setup_0.10.10_win-x64.exe` |
| 크기 | 81,222,654바이트 |
| SHA-256 | `0669211E7C2E67440CBDED1909E56477007E9F377167DA679F27FB0DEC0BD9C9` |

같은 값이 Release의 `checksums.txt`에도 있습니다. 다운로드한 파일의 해시가 위 값과 같을 때만 실행하세요. 설치 파일은 코드 서명이 되어 있지 않아 Windows 보안 알림이 나올 수 있습니다.

설치 위치는 `%LOCALAPPDATA%\Programs\WorkDock`입니다. 관리자 권한 없이 현재 사용자 계정에 설치됩니다. .NET 런타임을 따로 설치하지 않아도 됩니다.

## 한 번 켜 두면 이렇게 부릅니다

설치 후 WorkDock은 트레이에 상주합니다. 창을 찾을 때는 작업 표시줄의 숨겨진 아이콘을 확인하세요.

| 동작 | 결과 |
| --- | --- |
| 트레이 아이콘 왼쪽 클릭 | 도구 메뉴 |
| `Ctrl + Alt + W` | 도구 메뉴 |
| `Ctrl + Alt + Q` | 기능, 메모, 복사 기록, 기호를 한곳에서 검색 |
| `Ctrl + 마우스 오른쪽 클릭` | 커서 위치에서 도구 메뉴. 한글 입력기가 Alt를 같이 잡고 있어도 열립니다 |
| 트레이 아이콘 오른쪽 클릭 → **업데이트 확인** | GitHub의 최신 공개 버전과 비교 |

오른쪽 클릭에 붙는 조합은 환경설정에서 `Ctrl`, `Ctrl + Shift`, `Ctrl + Alt`, `Alt` 중 하나로 바꿀 수 있습니다. 최대화된 문서나 브라우저는 전체 화면으로 보지 않아 메뉴가 열립니다. 메뉴를 열지 않는 클릭은 그 프로그램에 그대로 전달됩니다.

메뉴는 커서 근처에 열리고, 연 직후 다른 창이 포커스를 가져가도 바로 닫히지 않습니다. 메뉴가 보이는 동안 `Esc`는 검색어가 있어도 메뉴를 닫습니다. 메뉴가 없으면 `Esc`를 가져가지 않습니다. 같은 프로그램은 한 번에 하나만 실행됩니다. 이미 켜져 있으면 새 창 대신 트레이 아이콘을 확인하라는 안내가 나옵니다.

## 무엇을 위한 프로그램인가

WorkDock은 작업 화면을 가리는 대형 창 대신, 지금 보고 있는 내용 옆에서 짧은 작업을 끝내게 합니다.

- 화면의 일부를 집어 표시하고, 글과 도형을 얹은 뒤 그 이미지를 다른 프로그램 위에 띄워 참고합니다.
- 긴 페이지는 사용자가 직접 스크롤한 뒤 한 장의 이미지로 이어 붙입니다.
- 복사한 글, 이미지, 파일의 기록과 출처를 로컬에 남깁니다.
- 메모의 처음 작성 시각은 바꾸지 않고, 이후 수정만 갱신합니다.
- 기호, 단위, 날짜, 환율, 분수 수식을 검색하거나 계산해 바로 복사합니다.
- 폴더 용량은 읽기만 합니다. 파일을 지우거나 옮기지 않습니다.

사용자 자료는 `%LOCALAPPDATA%\WorkDock`에만 저장됩니다. 메모, 캡처, 복사 기록, 설정은 자동으로 외부에 보내지 않습니다. 설치와 업데이트는 이 폴더를 지우거나 초기화하지 않습니다. 업그레이드 전에는 폴더를 다른 위치에 복사해 두는 편이 안전합니다.

## 업데이트 확인

프로그램을 켠 뒤 잠시 있으면 GitHub의 최신 공개 릴리스와 지금 버전을 한 번 비교합니다. 더 새 버전이 있을 때만 트레이 알림이 뜨고, 그 알림을 누르면 다운로드 페이지가 열립니다. 파일을 받거나 설치하지는 않습니다.

트레이 아이콘을 오른쪽 클릭하면 나오는 **업데이트 확인**은 같은 비교를 바로 다시 합니다. 이미 최신이면 그 사실을 알림으로 알려 주고, 연결이 안 되면 실패만 알려 줍니다. 이 확인이 GitHub에 보내는 것은 프로그램 이름과 버전뿐입니다.

## 화면 캡처

메뉴의 **캡처 · 녹화**에서 영역·직접 선택·모니터·전체 화면·스크롤 캡처를 고릅니다. 영역·스크롤·녹화는 같은 선택창을 사용합니다.

영역 캡처는 창과 세부 요소를 후보로 보여 주고, 직접 선택은 자동 인식 없이 드래그합니다. `Tab / Shift+Tab`으로 후보를 바꾸고, 선택한 뒤 화살표로 1픽셀, `Shift+화살표`로 10픽셀씩 옮길 수 있습니다. 너비·높이를 픽셀로 입력해 **크기 적용**을 누르면 왼쪽 위를 유지하며 화면 경계 안에서 맞춥니다. `Enter` 또는 **이 영역 사용**으로 확정하고 `Esc`로 취소합니다.

선택 바깥의 어두움, 십자선, 확대경, 윤곽선과 조절점은 환경설정에서 조절합니다. 작은 조절점의 실제 마우스 판정 영역은 더 넓습니다. 세부 요소 탐색이 늦어져도 드래그·확정·취소를 계속할 수 있습니다.

스크롤 캡처는 영역을 고른 뒤 직접 스크롤하고 **완료**를 누릅니다. 아래로 갔다 위로 돌아온 구간을 다시 붙이지 않도록 문서 위치를 추적합니다. 안내 창에 미리보기와 높이를 표시하며, 위치를 확신할 수 없는 프레임은 기존 결과에 섞지 않습니다. 너무 빠르게 이동해 위치를 잃으면 마지막 정상 위치 근처로 천천히 돌아오세요.

커서 포함 여부는 영역·직접 선택·모니터·전체 화면·스크롤마다 별도로 설정합니다. 사진 캡처는 기본 끔, 녹화는 기본 켬입니다. 색 추출 · 픽셀 측정에서는 한 점의 HEX·HTML 색을 확인하고 복사합니다.

## 편집

이미지 아래 도구막대에서 도형·선·화살표·펜·형광펜·텍스트·모자이크·블러·가림·지우개를 고릅니다. 원본 캡처 파일은 유지하고 편집 결과를 별도 이미지로 저장합니다.

| 입력 | 동작 |
| --- | --- |
| 일반 휠 | 세로 스크롤 |
| `Ctrl+휠` | 커서 위치를 기준으로 확대·축소 |
| `Shift+휠` | 가로 스크롤 |
| 가운데 버튼 드래그 | 보조 화면 이동 |

텍스트는 투명 배경으로 시작합니다. 우클릭에서 글자색·배경색·불투명도·투명을 고르고, 환경설정에서는 새 텍스트의 기본 배경을 지정합니다. `Ctrl+Enter`로 확정하고 `Esc`로 입력을 취소합니다. 확정한 글을 두 번 클릭해 고쳐도 스타일을 유지하며 스타일 변경도 Undo/Redo로 되돌립니다.

배율은 보기 상태입니다. 저장·복사 결과는 원본 픽셀 크기를 사용하고 선택 표시·도구막대·스크롤바를 넣지 않습니다.

## 화면 고정

편집 창의 핀 또는 캡처 후 **이미지 바로 고정**으로 이미지를 다른 프로그램 옆에 띄웁니다. 이미지를 끌어 옮기고 변·모서리로 원본 비율을 유지해 크기를 바꿉니다. `Ctrl+휠`로도 크기를 조절합니다.

마우스를 올리면 복사·편집·원본 폴더·비교·불투명도·항상 위·닫기 도구막대가 **이미지 밖**에 나타납니다. 기본은 아래이며 공간이 부족하면 위로 옮깁니다. 화면을 가득 채워 바깥 공간이 없으면 표시 크기·위치를 맞춰 도구막대가 이미지를 가리지 않게 합니다. 우측 상단 중복 메뉴는 없습니다.

드래그 중에는 캐시된 이미지를 사용하고 필요한 해상도만 나중에 보강합니다. 이미지 불투명도는 25~100%이며 도구막대 글자는 흐려지지 않습니다. 항상 위를 꺼도 창은 그대로 남습니다. `Esc`나 닫기는 고정 창만 닫으며 원본 캡처 기록은 삭제하지 않습니다.

## 복사 기록과 메모

**복사 기록**은 텍스트, 이미지, 파일 복사와 출처를 로컬에 남깁니다. 같은 내용이 다시 복사되어도 이전 기록을 지우지 않습니다. 수집은 트레이나 환경설정에서 켜고 끕니다. 비밀번호 관리자처럼 기록하면 안 되는 프로그램은 환경설정에서 제외할 수 있습니다.

**메모**는 제목과 내용을 자동 저장합니다. 처음 작성한 시각은 바뀌지 않고, 고친 내용만 갱신됩니다. 지운 메모는 휴지통에서 되돌릴 수 있습니다.

## 계산과 글

기호 검색은 한국어로 기호를 찾아 복사합니다. 단위 환산은 면적·길이·온도·데이터 등을 계산하고, 외화 환산은 공개 환율을 사용합니다.

날짜 · D-Day는 **목표일까지**, **시작일부터**, **기념일 표**, **날짜 이동**으로 나뉩니다. 시작일을 0일 또는 1일째로 계산할 수 있고, 100·200·300일 등의 기념일과 사용자 지정 항목을 표시합니다. 365일 후와 달력 1주년은 별도입니다.

분수 · 수식은 분수·괄호·첨자·근호를 미리보고 복사합니다. **모양 유지 복사**는 손글씨 윤곽선과 그림 형식을 사용합니다. **Word·PPT 수식 복사**는 MathML, **한글 수식 복사**는 별도 임시 문서의 수식 객체 연동을 사용합니다. 편집 가능한 수식은 대상 앱의 수식 글꼴을 사용할 수 있습니다. 한글 연동을 사용할 수 없으면 스크립트 복사로 구분해 안내합니다. 앱별 실제 붙여넣기 호환성은 추가 확인 범위입니다.

웹페이지 → Markdown의 주소 탭은 공개 HTML을 가져오고, 텍스트 탭은 직접 넣은 글을 사용합니다. 원문 복사와 구조 미리보기를 구분하며 중첩 목록과 표를 표시합니다. 설치 폴더의 브라우저 확장은 사용자가 고른 글과 출처를 이 컴퓨터에 저장합니다.

## 저장공간과 이미지 비교

저장공간 분석은 폴더를 펼치고 접는 계층 표로 보여 줍니다. 정렬은 같은 부모의 자식 안에서 적용하며 검색은 일치 항목의 조상 경로를 함께 남깁니다. 취소한 분석은 수집된 부분 결과로 보존하고 미완료 상태를 구분합니다.

대규모 분석은 사용자 DB와 분리된 임시 인덱스를 사용합니다. 선택 폴더의 트리맵·확장자 통계·중복 검사·CSV 내보내기를 제공합니다. 용량은 파일 길이의 경로별 합계이며 실제 디스크 할당량과 다를 수 있습니다. 분석은 원본 파일을 삭제하거나 수정하지 않습니다.

이미지 비교는 두 이미지를 겹쳐 확인합니다. 작업 공간과 문구 가공은 사용자 메뉴에서 제거했지만 기존 연결 데이터와 자료는 보존합니다.

## 환경설정

일반·단축키 / 화면 캡처 / 동영상 녹화 / 이미지 편집·고정 / 디자인 / 데이터·OCR / 고급·정보의 일곱 범주입니다. 좁은 창에서는 범주 선택창으로 전환하며 선택한 본문만 스크롤합니다.

**Windows 로그인 시 WorkDock 시작**을 켜면 현재 사용자 계정의 자동 실행 항목을 등록합니다. 기본은 끔이며 켜면 로그인 후 창 없이 트레이에서 시작합니다. Windows 시작 앱 설정에서 비활성화한 상태를 임의로 덮어쓰지 않습니다.

정보 화면에는 실제 버전과 작성자 Yoon Sangwon, [@ddanoni GitHub 홈](https://github.com/ddanoni)을 표시합니다. 데이터·OCR에는 백업·진단·Tesseract 설정을 둡니다. 기존 메모·복사 기록·캡처·설정을 초기화하지 않습니다.

## 화면 녹화

대상 모니터 또는 영역, FPS·화질·인코딩 형식을 고릅니다. **영역 다시 선택**을 완료하면 영역 버튼과 좌표가 함께 바뀌며 취소하면 이전 대상을 유지합니다. 시작·녹화·마무리 중에는 변경과 중복 실행을 막습니다.

녹화를 시작하면 설정창을 숨깁니다. 트레이 아이콘에서 제어창을 다시 열거나 녹화를 종료합니다. 지원 환경에서는 얇은 빨간 테두리·REC·경과시간을 표시하며, 시작 전 캡처 제외 검증에 실패하면 트레이만 사용합니다. 완료 화면에서 영상·저장 폴더 열기와 경로 복사를 제공합니다. 파일 마무리가 끝나야 저장 완료로 표시합니다.

녹화에는 사용자가 지정한 FFmpeg가 필요합니다. 소리 녹음은 포함하지 않습니다. 실제 Office 붙여넣기, 모든 모니터·DPI 조합, 로그인 실행과 실제 녹화의 최종 표시 제외 여부는 추가 현장 확인 범위입니다.

문제가 생기면 트레이 또는 환경설정에서 진단 로그를 확인하세요. 비밀번호·캡처·복사 본문을 GitHub Issue에 올리지 마세요. 신고 방법은 [SECURITY.md](SECURITY.md)를 확인하세요.
