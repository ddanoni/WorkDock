# WorkDock

WorkDock은 Windows에서 화면 캡처, 메모, 복사 기록, 기호와 단위 환산을 커서 옆의 작은 창으로 바로 쓰는 플로팅 업무 도구입니다. 프로그램을 켜면 큰 관리 창이 뜨지 않고 작업 표시줄에 남습니다. 필요할 때만 메뉴를 열어 도구를 꺼냅니다.

배포자: Yoon Sangwon  
현재 공개 버전: 0.10.9  
대상: 64비트 Windows

이 저장소는 설치 파일과 설명만 두는 공개 배포 장소입니다. 소스 코드, 개발 기록, 테스트 자료, 사용자 데이터는 올리지 않습니다.

## 다운로드

최신 설치 파일은 [Releases](https://github.com/ddanoni/WorkDock/releases/latest)에 있습니다.

| 항목 | 값 |
| --- | --- |
| 파일 | `WorkDock_Setup_0.10.9_win-x64.exe` |
| 크기 | 81,184,993바이트 |
| SHA-256 | `F04EDA649D29A9C094A7A27A79A5ACBF8FF14B9CAC5B74BE9D520E1ABF1BF4B2` |

같은 값이 Release의 `checksums.txt`에도 있습니다. 다운로드한 파일의 해시가 위 값과 같을 때만 실행하세요. 설치 파일은 코드 서명이 되어 있지 않아 Windows 보안 알림이 나올 수 있습니다.

설치 위치는 `%LOCALAPPDATA%\Programs\WorkDock`입니다. 관리자 권한 없이 현재 사용자 계정에 설치됩니다. .NET 런타임을 따로 설치하지 않아도 됩니다.

## 한 번 켜 두면 이렇게 부릅니다

설치 후 WorkDock은 트레이에 상주합니다. 창을 찾을 때는 작업 표시줄의 숨겨진 아이콘을 확인하세요.

| 동작 | 결과 |
| --- | --- |
| 트레이 아이콘 왼쪽 클릭 | 도구 메뉴 |
| `Ctrl + Alt + W` | 도구 메뉴 |
| `Ctrl + Alt + Q` | 기능, 메모, 복사 기록, 기호를 한곳에서 검색 |
| `Ctrl + 마우스 오른쪽 클릭` | 커서 위치에서 도구 메뉴 |
| 트레이 아이콘 오른쪽 클릭 → **업데이트 확인** | GitHub의 최신 공개 버전과 비교 |

오른쪽 클릭에 붙는 조합은 환경설정에서 `Ctrl`, `Ctrl + Shift`, `Ctrl + Alt`, `Alt` 중 하나로 바꿀 수 있습니다. 일반 오른쪽 클릭은 다른 프로그램에서 그대로 동작합니다.

메뉴는 커서 근처에 열리고, 바깥을 눌러도 검색 중이 아니면 바로 사라지지 않도록 되어 있습니다. 같은 프로그램은 한 번에 하나만 실행됩니다. 이미 켜져 있으면 새 창 대신 트레이 아이콘을 확인하라는 안내가 나옵니다.

## 무엇을 위한 프로그램인가

WorkDock은 작업 화면을 가리는 대형 창 대신, 지금 보고 있는 내용 옆에서 짧은 작업을 끝내게 합니다.

- 화면의 일부를 집어 표시하고, 글과 도형을 얹은 뒤 그 이미지를 다른 프로그램 위에 띄워 참고합니다.
- 긴 페이지는 사용자가 직접 스크롤한 뒤 한 장의 이미지로 이어 붙입니다.
- 복사한 글, 이미지, 파일의 기록과 출처를 로컬에 남깁니다.
- 메모의 처음 작성 시각은 바꾸지 않고, 이후 수정만 갱신합니다.
- 기호, 단위, 날짜, 환율, 분수 수식을 검색하거나 계산해 바로 복사합니다.
- 폴더 용량은 읽기만 합니다. 파일을 지우거나 옮기지 않습니다.

사용자 자료는 `%LOCALAPPDATA%\WorkDock`에만 저장됩니다. 메모, 캡처, 복사 기록, 설정은 자동으로 외부에 보내지 않습니다. 설치와 업데이트는 이 폴더를 지우거나 초기화하지 않습니다. 업그레이드 전에는 폴더를 다른 위치에 복사해 두는 편이 안전합니다.

## 업데이트 확인

프로그램을 켠 뒤 잠시 있으면 GitHub의 최신 공개 릴리스와 지금 버전을 한 번 비교합니다. 더 새 버전이 있을 때만 트레이 알림이 뜨고, 그 알림을 누르면 다운로드 페이지가 열립니다. 파일을 받거나 설치하지는 않습니다.

트레이 아이콘을 오른쪽 클릭하면 나오는 **업데이트 확인**은 같은 비교를 바로 다시 합니다. 이미 최신이면 그 사실을 알림으로 알려 주고, 연결이 안 되면 실패만 알려 줍니다. 이 확인이 GitHub에 보내는 것은 프로그램 이름과 버전뿐입니다.

## 화면 캡처

캡처는 메뉴의 **캡처 · 녹화**에서 고릅니다.

**영역 캡처.** 마우스가 잠시 머물면 창과 단추를 제안하고, 드래그로 직접 고를 수도 있습니다. 영역은 `Enter` 또는 확인으로 확정합니다. 제안 영역을 한 번 클릭해 바로 확정하는 동작은 환경설정에서 켤 수 있으며, 기본은 꺼져 있습니다.

**직접 선택 캡처.** 자동 인식 없이 드래그만으로 영역을 고릅니다.

**모니터 선택 캡처.** 고른 모니터 전체를 담습니다.

**전체 화면 캡처.** 연결된 모니터를 한 장으로 담습니다.

**색 추출 · 픽셀 측정.** 화면의 한 점을 클릭해 색을 읽습니다. 결과는 HEX와 HTML 색으로 보여주고, 복사한 색만 목록에 남습니다. 영역 픽셀 크기를 재거나 주 모니터를 바로 캡처할 수도 있습니다. 몇 초 뒤에 찍는 지연 캡처는 없습니다.

캡처 직후에는 편집 창이 열립니다. 환경설정에서 편집 대신 화면에 바로 고정하도록 바꿀 수 있습니다. 원본 파일은 캡처 기록에 남고, 편집본은 별도의 파일로 저장됩니다.

## 스크롤 캡처

긴 문서나 웹 페이지를 한 장으로 남길 때 씁니다.

1. 스크롤 캡처를 열고, 이어 붙일 영역을 드래그한 뒤 `Enter`로 시작합니다.
2. 그 창에서 직접 스크롤합니다. 프로그램이 휠을 대신 돌리지는 않습니다.
3. 화면 밖의 안내에 있는 **완료**를 누릅니다. **취소**와 `Esc`는 그 캡처만 중단합니다.

결과는 선택한 영역의 너비를 유지하고, 새로 드러난 높이만큼 길어집니다. 앞 화면과 겹치는 부분을 확신할 수 없는 프레임은 결과에 넣지 않습니다. 가상 목록처럼 스크롤해도 픽셀이 일정하게 움직이지 않는 앱은 이음이 빠지거나 짧아질 수 있습니다.

## 편집

편집 창의 이미지 아래에서 도구를 고릅니다. 도구 단추를 누르면 그 도구가 바로 켜지고, 오른쪽 클릭이나 펼침으로 옵션을 엽니다.

- 도형: 사각형, 원, 삼각형
- 선과 화살표: 끝 모양은 없음, 삼각형, 열린 화살촉, 마름모, 원형
- 펜, 형광펜, 글
- 모자이크, 블러, 검정 가림
- 지우개, 되돌리기, 다시 실행
- 색과 굵기

글은 상자를 만든 뒤 그 자리에서 입력합니다. `Ctrl + Enter`로 확정하고, `Esc`는 그 입력만 취소합니다. 입력 중인 상자와 확정된 글은 끌어 옮기고, 확정된 글은 두 번 클릭해 다시 고칩니다. 빈 글은 저장하지 않습니다. 지우개와 모자이크, 블러는 얹은 표시만 바꾸고 캡처 원본 파일은 그대로 둡니다.

긴 캡처는 창 안에 통째로 축소되지 않습니다. 이미지 위에서 휠을 올리면 확대되고 내리면 줄어들며, 가운데 단추를 누른 채 끌면 확대된 부분을 이동합니다.

## 화면 고정

웹, 한글, 프레젠테이션을 보면서 방금 집어 둔 영역만 옆에 두고 따라 적을 때 씁니다. 편집 창의 핀을 누르면 그 이미지가 테두리 없는 창으로 뜨고, 편집 창은 닫힙니다. 환경설정에서 캡처 후 동작을 **이미지 바로 고정**으로 바꾸면 편집 창을 거치지 않고 바로 뜹니다.

고정된 이미지는 다른 프로그램보다 위에 있습니다. 한글이나 브라우저를 눌러도 그 위에 남습니다. 이미지를 끌어 옮기고, 변이나 모서리를 끌면 가로세로 비율을 유지한 채 크기가 바뀝니다. 두 번 클릭하면 화면에 맞는 크기로 돌아갑니다.

마우스를 올리면 다음이 나타납니다.

- **복사.** 이미지를 클립보드에 넣습니다.
- **편집.** 고정을 닫고 같은 이미지의 편집 창으로 돌아갑니다.
- **원본 폴더.** 캡처 파일이 있는 폴더를 엽니다.
- **비교에 넣기.** 그 이미지를 비교 창에 올립니다.
- **불투명도 조절.** 25%에서 100%까지 막대로 고릅니다. 뒤의 글을 비치게 할 때 씁니다.
- **항상 위 전환.** 다른 프로그램 위에 둘지 끕니다. 고정할 때는 켜진 상태입니다.
- **닫기.** 고정 창만 닫습니다.

고정 창이 선택된 상태에서 `Esc`를 눌러도 그 창만 닫힙니다. 다른 프로그램에서 글을 쓰는 동안의 `Esc`는 가져가지 않습니다. 창을 닫아도 캡처 기록의 파일은 지워지지 않습니다. 좁은 이미지에서도 도구는 숨지 않고, 아래로 넘치면 이미지 위에 붙습니다.

## 복사 기록과 메모

**복사 기록**은 텍스트, 이미지, 파일 복사와 출처를 로컬에 남깁니다. 같은 내용이 다시 복사되어도 이전 기록을 지우지 않습니다. 수집은 트레이나 환경설정에서 켜고 끕니다. 비밀번호 관리자처럼 기록하면 안 되는 프로그램은 환경설정에서 제외할 수 있습니다.

**메모**는 제목과 내용을 자동 저장합니다. 처음 작성한 시각은 바뀌지 않고, 고친 내용만 갱신됩니다. 지운 메모는 휴지통에서 되돌릴 수 있습니다.

## 계산과 글

**기호 검색**은 네모, 원, 화살표, 수식 문자를 한국어로 찾아 복사합니다.

**단위 환산**은 면적, 길이, 온도, 데이터 크기 등을 기준값으로 계산합니다.

**외화 환산**은 공개된 환율을 기준으로 금액을 바꿉니다. 네트워크가 필요합니다.

**날짜 · D-Day**는 두 날짜의 차이와 날짜 이동을 계산합니다.

**분수 · 수식**은 분수를 미리보고, 문서에 붙일 이미지와 유니코드로 복사합니다. 붙여 넣은 이미지는 나중에 수식 객체로 다시 고칠 수 없습니다.

**문구 가공**은 공백, 줄바꿈, 기호를 정리합니다.

**웹페이지 → Markdown**은 공개 웹페이지를 Markdown으로 가져옵니다. 가져오는 범위는 공개 HTML에서 읽을 수 있는 내용입니다.

설치 폴더에는 브라우저에서 고른 글을 로컬로 보내는 확장 설치 스크립트도 함께 들어 있습니다. 확장은 사용자가 선택한 글과 출처를 이 컴퓨터에 저장합니다.

## 저장공간, 작업 공간, 이미지 비교

**저장공간 분석**은 고른 폴더의 파일과 폴더 용량을 보여 줍니다. 심볼릭 링크는 따라가지 않고, 파일을 삭제하거나 수정하지 않습니다. 드라이브 요약, 확장자 분포, 같은 내용의 파일 검사, CSV 내보내기가 있습니다.

**작업 공간**은 프로젝트별로 메모, 복사 기록, 캡처를 묶어 둡니다. 원본 파일은 옮기거나 바꾸지 않습니다.

**이미지 비교**는 두 이미지를 겹쳐 다른 픽셀을 확인합니다.

## 환경설정

환경설정은 다음 항목으로 나뉩니다.

- 디자인: 시스템, 밝게, 어둡게. 강조 색과 모서리
- 일반: 마스코트, 회의 중 마스코트 끄기
- 화면 선택: 자동 인식, 십자선, 확대경, 윤곽선
- 편집 도구: 기본 색, 굵기, 모자이크와 블러 강도
- 이미지 고정: 불투명도, 도구막대
- 호출과 단축키
- 데이터와 OCR: 저장 폴더, 진단 로그, 백업, Tesseract 경로
- 고급 · 진단: 캡처 기록, 복사 기록, 저장공간 분석, 색 추출, 문구 가공, 작업 공간, 메모 휴지통, 진단 로그
- 프로그램 정보

화면 녹화는 별도 창에서 영역, 품질, 저장 위치를 고릅니다. 영상 인코딩에는 사용자가 지정한 FFmpeg가 필요합니다. 마이크 입력은 이 버전에 없습니다.

문제가 생기면 트레이의 **진단 로그 열기** 또는 환경설정의 진단 로그 폴더에서 `Logs`를 확인합니다. 비밀번호, 화면 캡처, 복사한 본문을 GitHub Issue에 올리지 마세요. 신고 방법은 [SECURITY.md](SECURITY.md)에 있습니다.
